> Human-facing branch for Invisible Shadow: crisis tracing, Silk Route
> logistics, geopolitical disturbance mapping, and the wider philosophical and
> practical logic of weak-signal detection inside the Terra ecosystem.

## Layer role

This repository is a philosophy-and-practice branch.

It should hold:

- Invisible Shadow concepts and deployable branch artifacts;
- logistics and crisis interpretation surfaces;
- branch-level evidence, release, citation, and audit logic;
- readable human entry into the project rather than only symbolic fragments.

It should not become:

- a toy shell with dramatic slogans and no structure;
- a donor governance repository;
- a broken citation copy from another repository;
- an undifferentiated storage dump.

## Reading path

1. `README.md`
2. `CITATION.cff`
3. `bookmarklet.js` or equivalent deployable artifact
4. branch-specific crisis, route, and analysis files

## Ecosystem position

- `FMP-CENTRAL-REPO` — central public hub
- `terra-translation-api` — semantic and infrastructural neighbor
- `AIUZ-Terra-codex` — ecosystem and practice layer
- `terra-legal` — donor governance and standards

## Operating rule

Invisible Shadow should remain readable for humans first.

Its task is to connect weak signals, routes, risk, and interpretation without
collapsing into decorative noise or citation incoherence.
